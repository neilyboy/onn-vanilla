Logins are sent only to your boxes and left out of settings exports. People can also add services on the TV in Live TV → Settings.

Don't have Dispatcharr yet? Install it in one command

On any always-on computer with Docker (Linux, Mac, Windows, NAS):

docker run -d --name dispatcharr --restart unless-stopped -p 9191:9191 -v dispatcharr:/data ghcr.io/dispatcharr/dispatcharr:latest

Open http://THAT-COMPUTER:9191, create your admin login, then M3U & EPG Manager → Add M3U → Xtream Codes for each provider (URL, username, password). Add each provider's guide under EPG too if it has one. Then come back here.

Channel list

Your channel list is built in Dispatcharr by the Lineup Manager plugin (Dispatcharr → Plugins → Import). It merges the same channel from all your providers, rebuilds every 2 hours, and lists what it leaves out. Guide layout, empty event slots and favorites are set on each TV in Live TV → Settings.

Movies & Series

Lets Live TV browse your providers' movies and TV series (turn on VOD for each provider in Dispatcharr's M3U settings first). Your Dispatcharr login is used once to create a limited "vanilla-tv" user for the box and isn't saved.

Who's watching

Profiles for Live TV. Each one puts its channel groups first and adds "on now" rows for its keywords, e.g. Dad: Westerns, Gunsmoke, Bonanza. Groups are your Dispatcharr group names.

Kids hides adult channels everywhere. A PIN locks switching to that profile, so put PINs on the grown-up profiles to keep kids in theirs.

Set up a box

  1. On the TV: Settings → System → About, click Android TV OS build 7 times until it says you're a developer.
  2. Go back to System → Developer options and turn on Wireless debugging. Open it.
  3. Choose Pair device with pairing code. Type the code and the IP:port from that popup here, then click Pair.
  1. Close the popup. Enter the IP address & Port shown on the Wireless debugging screen (a different port) and click Connect.
  1. On the TV: Settings → Device Preferences → About, click Build 7 times.
  2. Back to Device Preferences → Developer options, turn on USB debugging.
  3. Find the IP: Settings → Network & Internet → your Wi-Fi. Enter just the IP below.
