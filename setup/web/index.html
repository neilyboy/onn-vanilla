Live TV source

Enter your Dispatcharr address. Every box gets its single playlist and guide.

Not using Dispatcharr? Enter playlist URLs directly
Don't have Dispatcharr yet? Install it in one command

On any always-on computer with Docker (Linux, Mac, Windows, NAS):

docker run -d --name dispatcharr --restart unless-stopped -p 9191:9191 -v dispatcharr:/data ghcr.io/dispatcharr/dispatcharr:latest

Open http://THAT-COMPUTER:9191, create your admin login, then M3U & EPG Manager → Add M3U → Xtream Codes for each provider (URL, username, password). Add each provider's guide under EPG too if it has one. Then come back here.

Build my channel list

Merges the same channel from all your providers into one channel with automatic backups, reads each provider's real stream limit, and matches channels to the guide. Re-run it any time you add or change a provider. Your Dispatcharr login is only used for this and isn't saved.


    
Movies & Series

    
Lets Live TV browse your providers' movies and TV series (turn on VOD for each provider in Dispatcharr's M3U settings first). Uses the Dispatcharr login above once to create a limited "vanilla-tv" user for the box.

Who's watching

    
Profiles for Live TV. Each one puts its channel groups first and adds "on now" rows for its keywords, e.g. Dad: Westerns, Gunsmoke, Bonanza. Groups are your Dispatcharr group names.

    

    

    
    
Kids hides adult channels everywhere. A PIN locks switching to that profile, so put PINs on the grown-up profiles to keep kids in theirs.
